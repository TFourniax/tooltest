# DiffWitness for AI builders

The Guided view explains what the agent changed, what the selected evidence established, what remains uncertain and what action should come next. It avoids requiring Git-hunk or proof-protocol knowledge before the user can make a decision.

Every statement still maps to VERIFIED, OBSERVED, SUGGESTED or UNKNOWN. The Guided view can change language and ordering, but never the evidence underneath it. Users can switch to Technical view at any time without re-running proof or creating a duplicate project.

Deterministic explanations are available without another model bill. Optional AI can improve wording but cannot add facts or upgrade uncertainty.
