# DiffWitness for developers

Run independent executable experiments on the exact Git patch produced by Claude Code, Codex, another agent or a human.

DiffWitness distinguishes contrast, necessity, sufficiency, interaction and stability instead of compressing them into one confidence score. Certificates are bound to the Git content and evidence command. Completeness limits and inconclusive evidence stay explicit.

Protect is optional: builtin, external or off. Protect observations never become proof. The Debt Ledger preserves unresolved obligations and replayable repayment checks.

Start:

    dw doctor
    dw guard -- claude
    dw gate --base origin/main --candidate HEAD
