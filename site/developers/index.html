One independent boundary

Green is a result. Proof is a process.

The coding agent may write implementation and tests in one trajectory. DiffWitness freezes the resulting change, runs the evidence independently, and records exactly which claim class it earned.

  • LOCALCore execution stays in your repository and requires no hosted account.
  • MODEL-FREEProtect, Proof and Debt do not require an LLM or model API.
  • BOUNDCertificates belong to the exact Git tree and evidence command.
  • HONESTBudgets, instability and inconclusive evidence remain explicit.

DWPP v1

Five questions. No confidence theatre.

The protocol does not compress unlike claims into a single score. Each experiment answers a different, bounded question.

01 · CONTRASTDoes candidate evidence fail on the base and pass on the candidate?
02 · NECESSITYWhich actual production hunks can be removed before evidence fails?
03 · SUFFICIENCYWhich real-hunk subset is enough to satisfy the selected evidence?
04 · INTERACTIONDo individually removable hunks secretly depend on each other?
05 · STABILITYDo repeated isolated runs agree before a causal label is emitted?

Protect · optional runtime layer

Use our hooks. Keep your harness. Or use neither.

Protect can observe or stop supported high-confidence actions while an agent works. It never becomes proof of final software behavior.

builtin

DiffWitness hooks

Install supported Claude Code and Codex hook surfaces with an explicit policy. Provider trust remains provider-owned.

dw protect enable --policy standard
external

Your existing harness

Delegate live interception without changing Proof, Debt, Continuity or IdleProof semantics.

dw protect use external
off

No DiffWitness interception

Remove DiffWitness-managed hooks. Post-change evidence and debt accounting remain available.

dw protect disable

Debt as an obligation

A shortcut is not repaid because the warning disappeared.

The append-only, hash-chained Debt Ledger stores stable lineages, provenance and — where available — a replayable verification adapter. A repayment runs through the gate again.

  • MEASUREdw debt records causal, deterministic, historical and bounded heuristic signals separately.
  • PRIORITIZEdw health and dw plan surface the next bounded repayment mission.
  • REPAYdw repay -- claude constrains the task, evaluates the patch and replays the original claim.
  • VERIFYClosure requires the matching adapter or an explicit externally justified resolution.

Exact boundaries

What this proves. What it never will.

IT CAN

Establish bounded claims under your selected executable evidence and environment.

IT CAN

Invalidate a certificate when the bound content changes after proof.

IT CANNOT

Prove the whole program correct or make weak evidence strong.

IT CANNOT

Authenticate the author merely because a record is content-addressed.
