# The 20th Prompt Problem

The first prompt feels like leverage. The twentieth inherits a system containing decisions nobody explicitly remembers making.

Generation compounds output. It does not automatically compound understanding. A green check is not institutional memory, and another model's confidence score is not an independent experiment on the patch.

Machine-written software needs four layers of accountable control: bounded runtime protection, executable post-change evidence, explanation that cannot upgrade uncertainty, and persistent obligations that survive the merge.

Sphaira Lab builds instruments, not oracles. An instrument exposes a signal, its provenance and its limits. DiffWitness is instrument 01.
