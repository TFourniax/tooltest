# PM-008b — Accent-aware cited retrieval and FR/EN acceptance corpus

Acceptance fixed before implementation, 2026-09-23. Baseline main
`8c0481f5107c500b125cdfa368670c60c2ec8e9e`, tree
`c82908377a5f74a594c5d456debb42ad7e308fd6`.

The ASCII-only tokenizer fragments French words at accented letters. A recorded
`Réinitialisation sécurisée` objective is returned for `réinitialisation`, but
not for `reinitialisation` or `securisee`. This is a reproduced retrieval gap,
not evidence that the assertion or its Proof status is wrong.

Normalize lexical terms consistently for indexing, candidate selection, ranking
and file-path matching. Preserve original labels, payloads, queries, entity IDs,
event bytes/hashes and epistemic statuses. Exact-ID matching remains literal.
Keep the inexpensive ASCII path and the existing minimum term length. Rebuild
older derived indexes through the existing state-schema mechanism; no journal
migration, trusted cache bypass, external model or translation service.

Regression requirements: accentless and composed/decomposed French lookup,
English behavior, punctuation, old-index migration with unchanged journal bytes,
replaced/retired memory, exact citations/statuses and no persistent query text.
Add a deterministic, manually specified FR/EN corpus with positive, negative,
graph and exact-ID cases, distractors, precision/recall/rank results and explicit
failures. Do not tune or delete failing cases silently. The corpus measures these
bounded scenarios only, not arbitrary semantic or cross-language recall.

Required gates: targeted regressions, complete base/optional source suites,
installed consumer, existing 10k budgets and new retrieval corpus, existing
24-job matrix plus ProofBench/ContinuityBench/integrated, review and fresh main
qualification after any merge. HUMAN, larger histories, all remaining PM008
citations/freshness, PM001–018 and commercial release remain open.

## Local audit and qualification

The fixed corpus has 29 cases and 1,200 unrelated historical memories. Before
repair: French 9/17, English 12/12; after repair: French 17/17, English 12/12.
Both post-change macro precision/recall and positive-query MRR are 1.0 on this
synthetic corpus only. It includes negative queries, retired assertions, literal
short identities and bounded graph traversal. Source citations and DECLARED
statuses are checked against the originally appended events, not reconstructed
from search text. Accent folding may return homographs; it never merges their
identities or promotes authority.

Eight failing assertions preceded the repair. The final nine targeted tests pass.
Full suites before the last import-only adjustment and extra preservation test:
670 base tests (52 explicit skips), 670 optional tests (4 platform skips), PASS.
The old source baseline had 662 base tests (52 skips), PASS. Final exact CI must
cover all 671 tests; the earlier full runs are not relabelled as final-source runs.

The audit found the Core extraction gate pinned IdleProof a37cb4f while the
integrated journey used 242714f. Both now pin independently qualified main
2b919f7dddeaf3488091017a46f079d8c9718056. The real built wheel/packed sidecar
integration passes against that main. The wheel retrieval corpus and real
Core→IdleProof→Portal producer journey pass. Portal source-equivalent main tree
23cd5ad2 and IdleProof main also passed their local 340/251-test suites.

Two operator errors remain recorded: the initial language journey omitted its
explicit executable argument; the initial final targeted command ran from the
Portal directory. Their corrected invocations pass and do not erase the errors.
The initial full results, source-bound corpus, failure logs and hash manifest
are retained in `docs/qualification/evidence/PM_008B_*`. None establishes HUMAN
acceptance or completes the larger PM008 or commercial release scope.
