# PM-004a0 — Bind observed structure to immutable Git bytes

Before language expansion, test the existing structure provider's source claim.
It records HEAD's tree while traversing mutable working files. A dirty edit,
deletion, untracked file or symlink can therefore be associated with a tree that
does not contain those bytes. This is advisory-memory provenance, not forged
executed Proof. Branch follows PM-006 #94; merge requires qualified dependencies.

Acceptance recorded before implementation: capture one Git tree, enumerate its
regular source blobs and parse those exact bytes. Never follow working-tree
symlinks or import untracked source. A concurrent HEAD advance must not mix trees;
the next refresh detects it. Preserve component/symbol identities and statuses.
Bound file count, per-file bytes and total bytes; report omitted/unparsed sources
and truncated coverage. Invalidate old misbound derived indexes even when the
recorded tree matches. Preserve append-only memory and Proof certificates.

Regression-first dirty/deleted/untracked, Git modes, bounded coverage, cache upgrade
and HEAD-race checks; full continuity/platform/benchmark/product gates and fresh
main. MACHINE remains distinct from HUMAN. This correction does not itself add
multi-language providers or claim complete PM-004 acceptance.

## Bounded implementation review

Regular Git blob modes only (100644/100755); symlinks/submodules never resolve to
working-tree paths. Enumeration and batch blob reads use the same captured tree.
Each returned object is checked against its manifest ID, type, length and Git
blob content hash (SHA-1 or SHA-256 as indicated by the object ID). Blob loading
finishes before changing the derived index, so corrupt reads retain prior state.

Limits: 2,000 files, 1 MiB per file and 32 MiB of selected contents. The coverage
object names the selected extensions and scope; completeness refers to that
supported scope, not to all languages in a repository. Omitted files, unsupported
modes/paths and parse failures remain visible. File observations remain OBSERVED;
existing name-based call heuristics remain INFERRED. No source contents enter the
append-only journal or leave the machine.

The derived state changes to `continuity-state-5` to discard indexes produced from
mutable working files, including callers that disable structure refresh. Existing
component/symbol identity algorithms and historical journals remain unchanged.
