## Concrete design gate, before implementation

API all_branches=True with optional opaque string cursor, CLI --all-branches/
--cursor; original first-parent mode remains the default. Capture HEAD plus
refs/heads and refs/remotes (including remote-tracking copies only), not tags,
reflogs or unreachable objects. Sort/deduplicate exact commit tips; reject more
than256 captured refs rather than truncate scope. No branch names in journal.

Reuse bounded _git and _commit. Obtain native topo-order rows with explicit
captured tips and --parents, no replacements. Compare every selected row's
parents against the content-hash-verified raw commit header. Shallow or graft
rewrites therefore produce an explicit boundary, never a falsely complete page.
The existing first-parent file diff remains the meaning of changed_files; all
parents drive traversal, not a new causal interpretation of merge contents.

Bounded cursor carries format/order version, captured sorted tips, include-
messages policy, processed-row count and SHA256 of the exact ordered row prefix.
Replay that prefix on continuation before slicing the next page; reject changed
order/topology, bad types/duplicate keys/nonfinite values/unknown keys/digests,
oversized cursor and unavailable foreign tips before append. Cursor checksum is
consistency detection, not authentication or Proof. Equivalent local object
graphs may resume; unrelated repositories without the captured objects cannot.
Use at most64KiB cursor and16MiB traversal output, count<=1million, while original
15s command/60s page budget still caps work. At most100 commits are admitted per
page; earlier rows are only hashed, not reimported. No persistent parallel store.

Native topo ordering may differ after Git version/topology changes: reject a
prefix mismatch and restart from captured/new tips idempotently. A shallow
boundary returns an unconsumed cursor; after deepen, resume if prefix still
matches, otherwise require restart. No fetch, repair or graft modification by
product. Rechecking a prefix costs O(history) per page and remains an explicit
scaling limitation for PM012; do not call this incremental graph traversal.

Atomic journal append/dedupe retains concurrent-page and interruption safety.
Tests must include graft parent mismatch and missing non-first parents, prefix
changes, forged cursor metadata, ref movement and default-mode compatibility.
