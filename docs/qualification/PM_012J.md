## Recovered implementation and review

This work was recovered uncommitted from the interrupted September 23 session.
The provisional `PM-012i` name collided with existing historical IdleProof
qualification evidence, so this bounded Core lot is named **PM-012j**. Existing
PM_012I evidence is unchanged.

The implementation reuses configured standard-library JSON codecs, checks
ordinary duplicate-free objects with `dict` construction, and retains duplicate
key diagnostics, byte encodings and non-finite-constant rejection. Canonical
identity members are removed only from a freshly encoded complete event with
unambiguous membership; nested lookalikes use independent full encodings. The
reader validates as it parses and closes the stream even if validation fails.
All events still remain subject to full validation before the snapshot is exposed.

Rebuild uses bounded (2,048-event) runs only for four typed declaration kinds
without specialized lifecycle effects. UPSERTs and relationships remain in journal
order. Each run materializes lexical terms from its last assertion per entity;
legacy, lifecycle, task, code and artifact events retain sequential projection.
Secondary indexes are built after projection inside the same transaction. Unique
constraints remain active throughout. Lexical pairs use a WITHOUT ROWID primary
key, with derived schema 9 requiring rebuild of old schema-8 databases.

The original append deepcopy/ownership boundaries, journal protocol, event byte
limits, source authority, benchmark workload and all thresholds are unchanged.
There is no provider retry, main requalification, new dependency or deployment.
