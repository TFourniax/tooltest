qualify before merge. Canonical current state remains issue #74.

Regression-first selective decoding and retrieval equivalence; unchanged tamper,
append-race, cache-migration and lifecycle tests; 10k before/after measurement and
larger-history exploratory measurement, with failures explicit. Full remote gates
and fresh main required. This unit does not claim incremental append replay,
monorepo completeness or complete PM-012/Alpha acceptance. HUMAN NOT RUN.

## Review and measured limits

State schema 6 adds a reconstructible lexical term index and indexed critical
invariant flag. The small in-memory query tables lead SQL joins; parameters never
become SQL syntax or persistent query history. Seeds include every direct match,
exact ID, critical invariant and component relation. The complete two-hop set is
then ranked by the existing algorithm. No candidate top-k is introduced.
Mixed-graph comparisons against the former exhaustive selection preserve complete
results. Existing authority, task privacy, replay, tamper and race tests pass.

Local Windows, seven hot samples at 10k: median 261.395ms, p95 266.032ms, cold
274.884ms. Append/verify/rebuild 3.638578/0.655764/1.712875s. The 300ms hot and
existing 10k budgets pass this sample; this is not a universal latency guarantee.
Derived DB is 20,180,992 bytes. The index adds storage and rebuild cost.

Exploratory 50k under unchanged 10k limits FAILS: append 89.105946s, full verify
4.109201s, rebuild 11.371026s, cold 405.699ms, hot median 383.285ms / p95
385.163ms. DB 100,184,064 bytes. Repeated whole-history append validation remains
quadratic across batches and is the next material scaling bottleneck. Do not
report this as a qualified 50k product budget, incremental replay or full PM-012.
