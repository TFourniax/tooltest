# PM-003a — Bounded Git history bootstrap

Acceptance recorded before implementation, 2026-09-18. Dependency: existing
ProjectEvent admission, journal integrity and reconstructible state.

Add `dw state bootstrap-git` for an existing repository. Capture one commit and
walk its first-parent history in bounded pages; return an immutable next ref for
resumption. Re-running a page must be idempotent, including after a prior page or
an interruption before append. Validate the complete page before the existing
locked journal append. Never mutate HEAD, index or working files.

Observe immutable commit/tree/parent identities and first-parent changed paths,
including root commits, merges, Unicode paths and SHA-256 repositories. Verify
commit object content against its object ID. Disable Git replacement objects,
external diff/text conversion and lazy fetching. Bound individual subprocess
time/output, page collection time, commit object bytes, paths and commit count. Oversized or
invalid objects fail without importing a partial page; unavailable parent objects
are an explicit incomplete-history boundary, not an invented root diff.

Do not persist author emails, raw author headers, patches or source text. By
default keep only commit-message digest/length. Explicit `--include-messages`
adds bounded UTF-8 message previews as separate DECLARED entities. Commit/path
observations stay OBSERVED and never produce an executed Proof, a causal task
link, a human validation or an inferred rationale. Changed-path omission and
message truncation/decoding coverage must be explicit.

Tests precede implementation: pinned-history/dirty isolation, page resumption and
dedupe, late message opt-in, authority rejection and reader/transport parity,
root/merge behavior, missing parent boundary, corrupted/replaced objects,
process bounds and pre-append interruption. Preserve existing event IDs/history.
Full local continuity tests, remote gates and fresh-main qualification follow.

First-parent traversal intentionally does not import every side-branch commit.
This unit does not close Git rename/feature lineage (PM-005), UI history (PM-009),
all-branch bootstrap, whole-project Alpha or required real HUMAN qualification.
