# PM-004f — shared JavaScript and TypeScript syntax providers

Acceptance fixed before implementation. Depends on corrected Core #104 exact-main
qualification. Extend the existing source-bound FileExtraction contract,
transport and immutable-tree coordinator; do not add a second store or allocate
provider-owned Git identity. Python provider/results/IDs remain unchanged.

Bounded scope: JavaScript/JSX and TypeScript/TSX declarations, class methods,
literal static imports/re-exports and name-only calls. Use actual syntax trees,
never regex matches in strings/comments. Static declarations/import syntax is
OBSERVED; potential calls remain INFERRED and do not establish runtime dispatch.
Unsupported constructs, dynamic imports/require targets and type resolution must
not become invented observed dependencies or runtime call edges. No Proof.

Use optional pinned Tree-sitter packages; the dependency-free engine remains
usable. Missing/incompatible parser, invalid UTF-8 or syntax errors returns
explicit unparsed empty facts. No automatic installation/network call at runtime,
no evaluation of project code. Parser/source/node/fact limits must be bounded.
Module paths preserve JS/TS paths rather than claiming Python package semantics.

The coordinator and transport select the same provider by source suffix. Index
refresh includes the provider capability/version profile so installing/removing
optional grammars cannot leave a silently stale derived projection. All provider
results are source/authority-admitted before replacing any prior index. Retain
dirty/untracked isolation, immutable captured tree and source limits.

Tests must fail before implementation and cover actual JS/TS/JSX/TSX syntax,
Unicode, comments/strings/templates, malformed syntax/encoding, no optional
packages, source binding, authority, parser bounds, index refresh and exact-tree
isolation. Keep existing tests and add mandatory three-OS optional-provider jobs
using installed artifacts. Existing 21 jobs and three product workflows remain
required; optional-dependency skips do not qualify parser behavior.

This bounded provider set does not complete the full requested language set,
consumer adoption, cross-language resolution or PM-004. Global NOT ALPHA READY;
HUMAN NOT RUN. No release/tag before final global gates.
