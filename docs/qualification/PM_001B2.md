# PM-001b2 — Imported envelope admission

Baseline: `TFourniax/tooltest@8f6acb20267e337993efefc662100cccef5e8b05`,
tree `ef61d9d42c419993aa446c9552237c90ccc085f5`.
The sole active coordinated registry and append-only qualification journal remain
[issue #74](https://github.com/TFourniax/tooltest/issues/74).
This document defines a bounded correction, not full PM-001 or HUMAN qualification.

## Reproduced defect

The public `dw state ingest-envelope <file> --json` command accepted a repository-bound
envelope with `proof.accepted` equal to the string `"false"`. It returned zero, appended
five events and stored `accepted=true` / `proofs.accepted=1`. The status remained
`OBSERVED`: this reproduces data coercion, not a forged certificate or new false VERIFIED.
Debt points also underwent integer coercion; understanding metrics lacked admission
type/range checks. Malformed identity containers could raise uncontrolled exceptions.

## Admission rules

The bridge reuses strict JSON parsing and finite JSON validation. Duplicate object
members (including escaped-equivalent names), NaN, Infinity and overflow to infinity
are rejected before any append. This includes values in otherwise unused extensions.
Direct Python callers undergo the same finite-value and summary checks.

| Supplied field | Accepted value |
|---|---|
| proof.accepted | Boolean |
| debt.points | Integer >= 0, excluding booleans |
| debt.budget_passed | Boolean or null |
| understanding.coverage / feature_coverage | Integer 0–100, excluding booleans |
| understanding.knowledge_debt / feature_debt | Integer >= 0, excluding booleans |
| debt.open_lineages | Array of strings; existing lineage prefix validation remains |

The envelope root and repository/base/candidate bindings must be objects. Non-null
Proof, debt and understanding summaries must be objects. Errors name the failed field
without printing its supplied value. The public import command returns exit code 2
and a controlled diagnostic for ContinuityError, without an interpreter traceback.

Compatibility is deliberate: absent optional scalars retain legacy defaults; absent
or null optional summaries still mean no summary, and absent/null lineage lists still
mean no lineages. Explicit null is not a boolean or integer, so it is rejected for
accepted, points and understanding metrics. Valid false, zero, budget null and the
coverage endpoints retain their exact meaning. Valid native builder output is retained.

This is not full JSON Schema enforcement. It does not newly require legacy omitted
fields such as created_at, change identity formats, replace string/actor admission,
introduce an event profile, or alter dedupe compatibility. Those broader producer
contracts remain separate work. The published change-envelope-1 schema is unchanged.

## Authority, atomicity and review

All source checks run before building/appending the event batch. A rejected source
leaves existing journal bytes unchanged and cannot append a partial change/proof/debt
history. Manual imports remain OBSERVED even when accepted is true. Only the existing
authoritative Guard bridge may use trusted_proof; a false boolean cannot qualify Proof.
Existing journals, IDs, hashes, historical Proof and disposable cache semantics remain
unchanged. No new Portal data, network call, source upload or raw prompt is introduced.

Field checks are linear in the supplied data. Finite validation serializes the envelope
once in memory before existing repository identity checks and append. This unit adds
no new journal scan or schema-engine dependency; it does not establish new input-size
or long-history performance guarantees.

Seven regression tests initially reproduce 55 failed assertions and 17 exceptions on
the exact baseline. They cover public CLI rejection, scalar/range and container cases,
ambiguous/non-finite JSON, atomicity, false/zero/null semantics, optional legacy absence,
idempotency and valid native builder output. SQLite connections are explicitly closed.
The installed wheel Guard/debt/envelope journey also submits the malformed public
import and verifies an unchanged journal. Existing installed standalone native journeys
exercise valid producer output. Required gates include targeted and full suites,
platform/package matrix, ProofBench, ContinuityBench, integrated smoke, implementing
agent review and fresh exact-main after qualified merge. Exact runs/digests belong in #74.
